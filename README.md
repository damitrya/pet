# Mimio

Виртуальный компаньон поверх экрана Android (`com.damitrya.mimio`): лисёнок реагирует на касания,
музыку, звонки и поездку на машине.

- Анимации лисёнка и галерея для просмотра без телефона — [`tools/fox/README.md`](tools/fox/README.md).
- Самостоятельное поведение лисёнка (режимы активности, планировщик, настроение) — [`docs/wave6-activity.md`](docs/wave6-activity.md).
- Иконка приложения — `python3 tools/icon/make_icon.py --preview`. Чтобы собрать иконку из готовой
  картинки, положите её в `tools/icon/source.png` и запустите скрипт снова.

## Перед публикацией Mimio

`applicationId` сменился с `com.drivecompanion` на `com.damitrya.mimio`: для Android это другое
приложение. Старое не обновится, а встанет рядом; его настройки, настроение лисёнка и выбранный
Bluetooth в Mimio не попадут (данные приложений разделены, имена файлов настроек тут ни при чём).

На чистой установке проверить:
- первый запуск и выдачу разрешений (поверх приложений, геолокация, уведомления, Bluetooth, активность);
- запуск и остановку сервиса, уведомление и его кнопки;
- автозапуск после перезагрузки (`BootReceiver`);
- плитку быстрых настроек (название Mimio, включение/выключение);
- иконку в разных лаунчерах (круг, скруглённый квадрат);
- переход в AUTO по Bluetooth машины и обратно.
- тактильную отдачу (касание, долгое нажатие, момент «сердечка») и её отключение в настройках;
- «Скрыть» в уведомлении: лисёнок превращается в сердечко и только потом исчезает; «Остановить» — сразу.
  Отдельно: «Скрыть» → сразу «Показать» (лисёнок остаётся); торможение во время сердечка (скрывается сразу);
  «Скрыть» дважды (скрывается сразу); «Остановить» во время сердечка (никаких уведомлений после остановки);
- долгое нажатие и затем перетаскивание: персонаж переезжает без сердечек и смущения в конце.
- волна 5: каждое 5-е поглаживание — сердечко (быстрые поглаживания со смущением тоже); «Проверить отклик» в
  настройках во всех трёх режимах тактильной отдачи; батарея 15 % → 10 % → 1 % (с включённым и выключенным
  «Автоматически скрывать Mimio при 1% заряда»), зарядка во время облачка, Mimio не возвращается сам после
  остановки на 1 %; предпросмотр наклонов и сердечка в «Отладке» (в release — долгое нажатие на заголовок).
- волна 6: «Активность персонажа» — по умолчанию «Живой»; смена режима на запущенном лисёнке (без перезапуска);
  в «Спокойном» он засыпает через 3 мин без касаний, в «Живом» через 5, в «Игривом» через 8; за рулём
  (подтверждённое движение) нет сценок даже в «Игривом»; «Статистика поведения за сеанс» в «Отладке» и
  `adb logcat -s MimioActivity` (debug); касание, поглаживание, звонок и музыка прерывают сценку как раньше.
